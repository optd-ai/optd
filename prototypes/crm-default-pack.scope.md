# CRM Default Pack Prototype Scope

This prototype pack uses `metadata.namespace: default` and `metadata.name: crm`.

Odoo CRM docs emphasize: leads as a qualification step before opportunities,
pipeline stages, lost reasons, merging/similar leads based on email/phone, sales
teams/assignment, activities/next actions, lead scoring/enrichment, expected
revenue/probability/forecasting, and reports. This pack captures those as
ordinary resources/actions/hooks rather than special platform code.

## Included resources

- `lead`
- `contact`
- `company`
- `opportunity`
- `note`
- `activity`
- `task`
- `sales_team`
- `lead_status`
- `opportunity_stage`
- `activity_type`
- `lost_reason`

## Included relationships

- `contact_company`
- `opportunity_company`
- `opportunity_contact`
- `note_lead`
- `activity_lead`
- `activity_contact`
- `activity_opportunity`
- `task_opportunity`

## Included actions/hooks

- `convert_lead` -> emits operations to create company/contact/opportunity and
  transition lead
- `mark_won` -> transition opportunity to won
- `mark_lost` -> transition opportunity to lost with lost reason
- `log_activity` -> create activity and note
- `normalize_lead` -> patch/default fields before preview
- `validate_lead` -> validation warnings/errors
- `notify_crm_change` -> after-commit outbox exercise

## Seeds

Seeds are authored as pack sugar, but intended execution is normal changeset
operations generated by the CLI/apply path. The seed files therefore describe
rows for reference resources rather than a separate data plane.
